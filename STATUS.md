# STATUS

## What was built

**Share Your Local AI** — a beginner manual for running AI locally inside one household: Ollama on a main computer, opened safely to family devices on the same network. Plain-English networking, firewall basics, phone access, and an honest "when this is a bad idea" page. Education only; no cloud, no secrets, no personal data.

**Contents:**

- `docs/` — 10 Markdown pages: intro, what you need, install Ollama, open-to-network, firewall basics, phone access, when-not-to, setup-day checklist (tickable, printable), troubleshooting table (11 scenarios), glossary
- `build.py` + `build.sh` — dependency-light build script that converts `docs/*.md` into a complete static HTML site in `site/` (shared header, active-state nav, warm print-friendly CSS, internal .md links and anchors correctly rewritten)
- `assets/style.css` — styling (warm cream/amber theme, responsive, print stylesheet)
- `README.md` — overview, build instructions, positioning (distinct from homelab-self-hosting-guide and local-ai-handbook), Asdale Dynamics, LLC credit
- `LICENSE` — MIT, `Copyright (c) 2026 Asdale Dynamics, LLC`

## How to run it

```bash
./build.sh                          # builds site/ from docs/
python3 -m http.server 8000 --directory site   # optional local serving
```

Then open `site/index.html` directly in a browser, or visit http://localhost:8000. Requires Python 3 with the `markdown` package (`pip install markdown`). Build runs fully offline, reads only `docs/` + `assets/`, writes only `site/`.

## Known gaps

- Content describes macOS/Windows/Linux at the level a beginner needs; exact firewall setting names vary by OS version and may drift.
- The guide suggests Tailscale for away-from-home access but deliberately does not teach it — it's a separate project/viewpoint with its own risks worth its own guide.
- Internal anchor IDs are generated by markdown's `toc` extension; renaming headings slightly (e.g. adding punctuation) can invalidate cross-page anchor links. The audit script above can be re-run to catch that.
- No screenshot/tutorial imagery — all text and tables by design (keeps the build offline and light).
- Phone apps named (Reins on iOS, ChatterUI on Android) are good free picks as of writing; availability can change app-store to app-store.
